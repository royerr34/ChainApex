# ChainApex

ChainApex is a fault-tolerant, high-availability platform enabling real-time processing with auto-scaling capabilities, managed by a centralized service manager.

ChainApex is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/ChainApex.git`
2. `cd ChainApex`
3. Install in editable mode: `pip install -e .`

## Configuration

ChainApex is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
